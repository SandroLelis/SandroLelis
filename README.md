## Active work

### [versioned-ciphertext](https://github.com/SandroLelis/versioned-ciphertext)

A small, open-source Python pattern for lazy cryptographic schema migration.

- Self-describing ciphertexts with version headers
- Backend registry for transparent decryption
- AES-256-GCM and legacy AES-CBC examples
- MIT licensed
